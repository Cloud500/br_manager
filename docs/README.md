# BR Manager – Projektkonzept

## Übersicht

Der **BR Manager** ist eine webbasierte Anwendung zur digitalen Unterstützung der Betriebsratsarbeit. Das System ermöglicht die effiziente Verwaltung von Tagesordnungen, Protokollen, Beschlüssen, Dokumenten und Anwesenheiten – unter vollständiger Einhaltung der gesetzlichen Anforderungen des Betriebsverfassungsgesetzes (BetrVG) und der Datenschutz-Grundverordnung (DSGVO).
